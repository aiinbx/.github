# AI Inbx

AI Inbx is an email API for AI agents and SaaS platforms. One API to send and receive email. Replies land on the right thread as clean text, attachments as Markdown, and users can connect their own Gmail or Outlook.

- **Docs**: [docs.aiinbx.com](https://docs.aiinbx.com) · [Quickstart](https://docs.aiinbx.com/quickstart) · [API reference](https://docs.aiinbx.com/api)
- **TypeScript SDK**: `npm install aiinbx` · [docs](https://docs.aiinbx.com/sdks/typescript) · [npm](https://www.npmjs.com/package/aiinbx) · [source](https://github.com/aiinbx/aiinbx-ts)
- **Python SDK**: `pip install aiinbx` · [docs](https://docs.aiinbx.com/sdks/python) · [PyPI](https://pypi.org/project/aiinbx/) · [source](https://github.com/aiinbx/aiinbx-py)
- **CLI**: `npm install -g @aiinbx/cli` or `brew install aiinbx/tap/aiinbx` · [docs](https://docs.aiinbx.com/cli) · [source](https://github.com/aiinbx/cli)
- **MCP server**: [mcp.aiinbx.com](https://mcp.aiinbx.com) · [docs](https://docs.aiinbx.com/mcp)
- **Starters**: [email agents with Upstash](https://github.com/aiinbx/aiinbx-x-upstash-email-agent-starter) · [Mr Sales, an email agent on Next.js](https://github.com/aiinbx/mr-sales)
- **Pricing**: [monthly plans from $5](https://aiinbx.com/pricing), billed by email volume
